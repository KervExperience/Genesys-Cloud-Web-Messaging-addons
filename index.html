Genesys Web Messenger Transcript POC

This page is a standalone proof of concept for browser-based transcript download using Genesys Web Messenger.

What this example does
  • Loads the Genesys Web Messenger widget
  • Captures transcript lines client-side as messages arrive
  • Prompts the end user to save the transcript when the conversation is cleared
  • Prompts the end user to save the transcript when the conversation is disconnected
Note: Debug logging is disabled by default. Set debug to true to see console logs prefixed with [Genesys Transcript].

Test notes

  • Customer clear path uses MessagingService.conversationCleared
  • Disconnect path uses MessagingService.conversationDisconnected
  • Transcript content is built from MessagingService.messagesReceived
  • Messenger is configured to auto-open for ease of testing

If you do not want the Messenger to auto-open, set autoOpenMessenger to false in the config section below.
